## Project Overview
![Cover](/images/sipresta/sipresta-cover.png "w=360")

SIPRESTA is a web-based system designed to record and manage student achievements, specifically within the IT department. The system helps academic staff organize achievement data and identify top-performing students through a more structured and objective approach.

| My Role | Responsibilities |
|---|---|
| UI/UX Designer | - Analyzed the existing workflow and pain points<br> - Defined data structure and user flow<br>- Designed interfaces for data input and evaluation<br>- Improved usability and clarity across the system |

## Problem Statement & Goals

### The Problem

1. Student achievement data was not well organized.
2. Academic staff struggled to evaluate and rank students objectively.

Most existing conditions:

- Data was scattered and inconsistent  
- The process relied heavily on manual work  
- No clear system to compare student achievements  

### The Goal

Design a system that:

- Organizes achievement data in a clear and structured way  
- Supports fair and consistent evaluation  
- Helps identify top-performing students more efficiently  

## User Research & Insights

### User Research

I analyzed how achievement data was previously recorded and used by academic staff.

Key findings:

- Data was not standardized, making it difficult to compare  
- There was no clear evaluation system  
- Manual processes were time-consuming and prone to errors  

### User Persona

Primary users of this system are admin and academic staff.

| Goals | Input and manage data efficiently |

#### 2. Academic Staff

| Category | Details |
|---|---|
| Profile | Academic staff |
| Background | Uses data for evaluation and decision-making |

## Requirements

To translate insights into actionable design decisions, I defined the following requirements.

### User Requirements

1. Users need an easy way to input achievement data  
2. Users need a clear and understandable evaluation system  
3. Users need access to student rankings and performance insights  

### System Requirements
 
1. The system should standardize achievement data  
2. The system should generate rankings automatically  
3. The system should support consistent evaluation criteria
