## Project Overview
![Cover](/images/sipresta/cover.png)

SIPRESTA adalah sistem berbasis web yang dirancang untuk mencatat dan mengelola prestasi mahasiswa, khususnya di lingkungan jurusan TI. Sistem ini membantu pihak akademik dalam mengatur data prestasi dan menentukan mahasiswa berprestasi secara lebih terstruktur dan objektif.

| My Role | Responsibilities |
|---|---|
| UI/UX Designer | - Menganalisis alur sistem dan masalah yang ada<br> - Menentukan struktur data dan alur pengguna<br>- Mendesain interface untuk input dan evaluasi data<br>- Meningkatkan kejelasan dan kemudahan penggunaan sistem |

## Problem Statement & Goals

### The Problem

1. Data prestasi mahasiswa belum terorganisir dengan baik.
2. Pihak akademik kesulitan dalam melakukan evaluasi dan menentukan peringkat mahasiswa secara objektif.

Kondisi yang terjadi:

- Data tersebar dan tidak konsisten  
- Proses masih banyak dilakukan secara manual  
- Tidak ada sistem yang jelas untuk membandingkan prestasi mahasiswa  

### The Goal

Merancang sistem yang:

- Menyusun data prestasi secara rapi dan terstruktur  
- Mendukung proses evaluasi yang adil dan konsisten  
- Membantu menentukan mahasiswa berprestasi dengan lebih efisien  

## User Research & Insights

### User Research

Saya menganalisis bagaimana data prestasi sebelumnya dicatat dan digunakan oleh pihak akademik.

Temuan utama:

- Data tidak terstandarisasi sehingga sulit dibandingkan  
- Tidak ada sistem evaluasi yang jelas  
- Proses manual memakan waktu dan rentan terjadi kesalahan  

### User Persona

Pengguna utama sistem ini adalah admin dan staff akademik.

#### 1. Admin

| Category | Details |
|---|---|
| Profile | Admin jurusan |
| Background | Bertanggung jawab dalam menginput dan mengelola data |
| Goals | Menginput dan mengelola data dengan cepat dan rapi |
| Behavior | Mengupdate data secara berkala |
| Frustrations | Proses manual lambat dan tidak efisien |
| Motivations | Menginginkan sistem yang mempermudah pekerjaan |

#### 2. Staff Akademik

| Category | Details |
|---|---|
| Profile | Staff akademik |
| Background | Menggunakan data untuk evaluasi dan pengambilan keputusan |
| Goals | Memahami performa mahasiswa dengan jelas |
| Behavior | Mengakses data saat dibutuhkan |
| Frustrations | Data sulit dipahami dan tidak terstruktur |
| Motivations | Membutuhkan informasi yang akurat dan terorganisir |

Persona ini membantu memastikan desain tidak hanya mempermudah pengelolaan data, tetapi juga mendukung proses pengambilan keputusan.

## Requirements

Untuk menerjemahkan insight menjadi keputusan desain yang bisa diterapkan, saya menentukan beberapa requirement utama.

### User Requirements

1. Pengguna membutuhkan cara yang mudah untuk menginput data prestasi  
2. Pengguna membutuhkan sistem evaluasi yang jelas dan mudah dipahami  
3. Pengguna membutuhkan akses ke hasil ranking dan insight performa  

### System Requirements
 
1. Sistem harus menstandarisasi data prestasi  
2. Sistem harus dapat menghasilkan ranking secara otomatis  
3. Sistem harus mendukung evaluasi yang konsisten  

## Design Process

### Wireframes to Lo-Fi to Hi-Fi

Pada tahap awal, saya mengeksplorasi:

- Menyederhanakan alur input data  
- Menyusun form agar lebih terstruktur dan jelas  
- Mengurangi kompleksitas tampilan  

Solusi akhir difokuskan pada kejelasan data, struktur yang rapi, dan efisiensi dalam penggunaan sistem.

### Core Features

![showcase](/images/sipresta/showcase.png)

| Feature | Description |
|---|---|
| **Achievement Input System** | Memungkinkan input data prestasi secara terstruktur dan konsisten |
| **Ranking System** | Menghasilkan peringkat mahasiswa secara otomatis berdasarkan kriteria tertentu |
| **Dashboard Overview** | Menampilkan ringkasan performa dan insight data secara jelas |

### Usability Considerations

Beberapa hal yang menjadi pertimbangan dalam desain:

- Struktur data yang jelas memudahkan pengelolaan informasi  
- Proses otomatis mengurangi kesalahan manual dan menghemat waktu  
- Tampilan yang sederhana membantu pengguna memahami sistem dengan cepat
