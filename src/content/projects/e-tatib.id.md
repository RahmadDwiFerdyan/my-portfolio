## Project Overview

Sistem tata tertib mahasiswa berbasis web untuk membantu proses pencatatan pelanggaran, monitoring mahasiswa, dan pengelolaan data pelanggaran secara terpusat.

### Tech Stack
- Laravel
- PHP
- SQL Server
- Bootstrap
- JavaScript
- HTML
- CSS

## Key Features
1. Pencatatan pelanggaran mahasiswa
2. Monitoring data mahasiswa
3. Analitik pelanggaran mahasiswa
4. Manajemen data pelanggaran
5. Multi-role access
6. Dashboard monitoring

## What I Do
- Mendesain struktur database dan pengelolaan data pelanggaran mahasiswa
- Mengembangkan fitur pencatatan dan monitoring pelanggaran
- Mengimplementasikan dashboard monitoring dan analitik data
- Mengembangkan sistem multi-role untuk pengelolaan data mahasiswa
