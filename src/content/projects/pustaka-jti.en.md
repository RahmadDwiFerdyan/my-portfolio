## Project Overview
![Cover](/images/pustaka-cover.png "w=540")

Pustaka JTI is a web-based repository platform designed to store and manage academic documents within the IT department. It helps students and staff access resources in a more organized and structured way.

| My Role | Responsibilities |
|---|---|
| UI/UX Designer | - Conducted problem analysis on existing system<br> - Defined information architecture and content structure<br>- Designed navigation and document organization system<br>- Created user-friendly interface for document access |

## Problem Statement & Goals

### The Problem

1. The existing repository system was poorly organized and difficult to navigate.
2. Many important documents were scattered and not fully digitized.

Most existing conditions:

- Documents were not categorized clearly  
- Users struggled to find relevant resources  
- No proper system to manage and maintain documents  

### The Goal

Design a repository system that:

- Organizes documents in a clear and structured way  
- Makes it easy for users to find and access resources  

## User Research & Insights

### User Research

I analyzed the existing system and observed how users interact with academic resources.

Key findings:

- Users need a clear structure to find documents quickly  
- Lack of categorization creates confusion  
- Accessing documents takes too many steps

## Requirements

To translate insights into design decisions, I defined key requirements.

### User Requirements

1. Users need a simple way to find documents  
2. Users need clear categorization  
3. Users need easy access to resources  

### System Requirements
 
1. The system should support structured document organization  
2. The system should provide search and filtering  
3. The system should be scalable for future content
