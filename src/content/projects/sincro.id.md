## Project Overview

Sistem manajemen tugas berbasis web untuk membantu koordinasi pekerjaan lintas divisi melalui assignment tugas, monitoring progres, dan approval tugas secara terpusat.

### Tech Stack
- Laravel 
- Node.js
- MySQL
- TailwindCSS

## Key Features
1. Assignment & monitoring task
2. Approval workflow
3. Dependency task
4. Dashboard multi-divisi
5. Multi-role access

## What I Do
- Mendesain struktur database dan hak akses pengguna
- Mengembangkan fitur assignment, dependency task, dan monitoring progres
- Mengimplementasikan dashboard monitoring tugas lintas divisi
